# Phase 3 — Object-Oriented Python

OOP learned through building real systems, not abstract theory.

## Topics

- Classes, objects, instance and class attributes
- Methods, classmethods, staticmethods
- Inheritance, composition, polymorphism
- Encapsulation, properties, dunder methods
- Operator overloading
- Abstract base classes, protocols
- Dataclasses (OOP perspective)

## Projects

OOP concepts are taught through progressively complex systems (e.g., inventory management, plugin architecture, payment system).
