# Your Solutions — Phase 1: Core Python

Implement your exercise solutions here. **Do not copy solutions** — write your own.

## Naming convention

Match the exercise slug:

```
01_personal_expense_calculator.py
02_temperature_converter.py
```

## Workflow

1. Read the problem in `../problems/`
2. Implement here
3. Run tests: `pytest ../tests/test_XX_<slug>.py -v`
4. Commit: `scripts/commit_exercise.sh feat core XX_<slug>`
