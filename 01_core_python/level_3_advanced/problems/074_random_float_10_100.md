## Objective

Generate a random floating-point number between 10.0 and 100.0 using Python's built-in `random` module.

## Requirements

1. Import the appropriate functionality from Python's `random` module.
2. Generate a random floating-point number between 10.0 and 100.0.
3. Both boundary values (10.0 and 100.0) may be included.
4. Return or print the generated value.
5. The result must be of type `float`.
6. Each execution should generate a new random value (unless the random generator is explicitly seeded).
7. Do not hardcode the output.
