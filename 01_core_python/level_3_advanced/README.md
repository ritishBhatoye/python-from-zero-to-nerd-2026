# Level 3: Advanced

## Overview

Advanced exercises requiring comprehensive Python knowledge, use of standard library, algorithms, and advanced techniques. For programmers ready to tackle complex problems.

## Topics Covered

- Object-Oriented Programming (OOP)
- Generators and iterators
- Decorators
- Regular expressions (regex)
- Exception handling and custom exceptions
- Recursion and dynamic programming
- Algorithms and data structures
- Standard library modules (re, random, zlib, itertools, etc.)
- Performance optimization
