# Level 2: Intermediate

## Overview

These exercises are for someone who has learned Python basics and has some programming background. Problems require using 2-3 Python classes or functions together.

## Topics Covered

- List comprehensions
- File I/O
- String processing and regex basics
- Algorithms (sorting, searching)
- Functional programming (map, filter, lambda)
- Data transformations
- Multiple data structures combined
