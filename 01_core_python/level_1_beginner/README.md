# Level 1: Beginner

## Overview

These exercises are for someone who has just completed an introductory Python course. They cover fundamental concepts that can typically be solved with 1-2 Python functions or classes.

## Topics Covered

- Basic I/O and printing
- Variables and data types
- Arithmetic operations
- Strings and string manipulation
- Lists, tuples, and dictionaries
- Basic loops (for, while)
- Simple conditionals (if/elif/else)
- Functions and basic classes
- Simple list comprehensions
