# Phase 0 — Environment & Engineering Setup

Setting up a professional Python development environment before writing any code.

## Topics

- Python installation and version management
- Virtual environments
- Package management (pip, pyproject.toml)
- Project structure conventions
- `.gitignore` and repository hygiene
- Formatting (ruff) and linting
- Testing setup (pytest)
- Git workflow

## Diagnostics

The `diagnostics/` directory contains the initial Python diagnostic challenge — a practical test that covers core Python concepts and determines the starting point in the curriculum.
