# Phase 11 — Algorithms & Data Structures

Implementing foundational data structures and algorithms from scratch in Python.

Linked lists, stacks, queues, hash tables, trees, BSTs, heaps, priority queues, graphs, tries, union-find

Searching, sorting, recursion, backtracking, greedy, dynamic programming, graph traversal, shortest paths, topological sort

Every implementation includes correctness analysis, time/space complexity, and Python-specific trade-offs.
